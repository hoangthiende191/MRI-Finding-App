MRI Radiology Database System

Three database applications for patient, condition-based MRI retrieval, and similar-image search.

1

Patient Search

Retrieve the radiology report and MRI images for a patient ID.

 2

Conditional Search

Filter MRI images using patient ID, sequence type, and orientation.

 3

Similar MRI Search

Select one MRI image and retrieve visually similar images.
Architecture: MySQL stores MRI metadata and file paths. Flask reads the .ima/DICOM files and returns PNG previews to the browser. The original MRI files remain outside the database.
